## 边界与限制

- 笔记内的 `_snapshots_local/...`、`../notes/...` 等路径指向研究库本地，在本发布包中不可达；**原文请走每篇元信息里的来源链接**（arXiv/ACL/厂商官网，均为公开页面）。
- `snapshots_meta/` 存抓取时间与 SHA-256，用于核对"笔记引用的是哪个版本的原文"，不含原文内容。
- **原文快照（PDF/HTML）不随本包分发**（第三方版权与体积原因），永久留存于研究库本地。
- 所有效果数字均为来源自报、未复现；M-112/M-116 为超窗来源（仅历史对照用途）。原则层对这批证据的吸收方式与冲突调和见 [principles/07_evidence.md](../principles/07_evidence.md) v0.22 节。
