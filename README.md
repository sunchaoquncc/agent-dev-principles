# Agent 开发核心原则（给开发用的 AGENTS.md）

一套供 agent 开发会话按需读取的评审清单：**26项有条件建议与历史/候选条目 + 复核触发器**，按prompt、上下文、harness及评测、安全组织。

## 怎么用

1. **最简用法**：把根目录 `AGENTS.md` 复制到你的 agent 开发项目根目录（多数 agent 工具会自动加载根 AGENTS.md）；供开发助手使用，不原样放入业务agent系统提示。
2. **渐进式披露**：核心文件只放必看的薄层（26 项规则）；细则在 `principles/01—05` 按需读，不要全量加载。`principles/06_cases.md` 是案例索引。
3. **状态**：◐有条件；🧪待验证；历史仅对照。无当前跨模型验证保证。
4. **元规则**：逐条绑定适用模型、环境及证据日期；2026-10-13为审查日，不是当前模型验证日。模型换代、平台变化、复现异常或6个月例行扫描时复核；托管不自动废弃治理目标。

## 文件结构

```
AGENTS.md                  # 核心层：26项评审条目 / 复核触发器（按开发任务读取）
principles/

├── 02_context.md          # 上下文层细则与证据
├── 03_harness.md          # harness 层细则与证据

└── 06_cases.md            # 案例索引（生产级 / 实验 / 反向更新样本）
```
